# Performance and Lighthouse

This doc summarizes performance-related changes and how to run audits. For the full list of actionable changes, see [UI Architect Recommendations](UI-ARCHITECT-RECOMMENDATIONS.md) and the Lighthouse plan.

## Running a Lighthouse audit

- **Local:** Build with `hugo --minify`, serve `public/` (e.g. `npx serve public` or `hugo server --renderToDisk`), then run Lighthouse from Chrome DevTools or:
  ```bash
  npx lighthouse http://localhost:3000 --view --preset=perf
  ```
- **Deployed:** Use [PageSpeed Insights](https://pagespeed.web.dev/) or the same CLI against the live URL. Prefer mobile (4G) for Core Web Vitals.
- **CI:** Add [Lighthouse CI](https://github.com/GoogleChrome/lighthouse-ci) to `.github/workflows` to run on deploy and fail if scores drop below thresholds.

## Implemented optimizations

- **LCP:** Critical CSS inlined; LCP image (hero avatar) preloaded (280×280 WebP on home); hero background image preloaded on home; `decoding="async"` and `fetchpriority="high"` on hero/about images; avatar dimensions aligned to `--avatar-wide` (140) for CLS.
- **Fonts:** Inter and JetBrains Mono are self-hosted (woff2 in `static/fonts/`); Inter variable font preloaded; `font-display: swap` in `@font-face`; no Google Fonts request.
- **Third-party:** Mermaid preconnect only on pages that contain Mermaid diagrams; Swup is self-hosted (bundle in `assets/js/vendor/swup.umd.js`) and no longer loaded from jsDelivr.
- **Images:** Site-level render-image hook adds `loading="lazy"`, `decoding="async"`, and `width`/`height` when the image is a Hugo image resource.
- **About page:** Header photo uses `width="200"` `height="200"` (matches `--about-photo-desktop`) and `decoding="async"`.

## Self-hosted font paths

Font `@font-face` rules are generated by the theme partial `font-face-css.html` and inlined in the layout; font URLs use `relURL` so they respect `baseURL` (including subpaths like GitHub Pages project sites).

## Server and delivery (when you control the host)

- **Caching:** Serve fingerprinted assets (e.g. `/js/app.min.xxx.js`) with long-lived cache:
  ```
  Cache-Control: public, max-age=31536000, immutable
  ```
  Keep HTML cache short or use `stale-while-revalidate`.
- **Compression:** Enable Brotli or gzip for HTML, CSS, and JS.
- **Early Hints (103):** If the server supports it, send `Link` headers for the LCP image and main stylesheet so the browser can preload before parsing HTML.

## Success criteria

- **LCP** &lt; 2.5s, **INP/FID** &lt; 200ms, **CLS** &lt; 0.1, **Performance score** &gt; 90 where feasible.
- Re-run Lighthouse after each change to isolate impact.
